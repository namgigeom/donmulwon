# DONMULWON GUI assets

## Tiny Creatures

The GUI character sprites use the **Tiny Creatures** 16x16 pixel-art set by Clint Bellanger, with Kenney as collaborator.

Source: https://opengameart.org/content/tiny-creatures
License: CC0 1.0 Universal

The set contains the animal sprites used for:
- 현무 — turtle
- 김선달 — crow/raven
- 이묵 — asp/snake
- 너부리 — raccoon
- 알프레도 — cat

The application downloads and caches the small CC0 archive on first run so the repository does not need to store the binary archive itself.
